# STRATOS Outreach Edition

This is a web app for satellite communication analysis and outreach. The project uses React with TypeScript and Vite for the frontend.

## What it does

The app helps analyze satellite communication data and provides an interface for tracking and managing outreach activities.

## Getting Started

You need Node.js installed on your computer to run this.

1. Install all the dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. Open your browser and go to the local URL shown in the terminal (usually http://localhost:3000)

## Tech Stack

- React 19 for the UI
- TypeScript for type safety
- Vite for fast development and building
- React Router for navigation
- Static mock data for testing (no API key required)
